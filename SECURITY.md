# Security Policy

Business Workflow Engine is an early MVP and is not represented as production-hardened or certified for regulated workloads. Do not use it to process sensitive or regulated data without completing an independent security and operational review.

## Supported versions

There are no stable releases yet. Security fixes are developed against the latest commit on `main`; older commits and deployments do not receive a separate support guarantee.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue or pull request. Use GitHub's **Report a vulnerability** feature in the repository's Security tab to send a private report. If private vulnerability reporting is unavailable, contact the repository maintainer through GitHub before sharing technical details.

Include the affected commit or deployment version, the impact you observed, and concise reproduction steps. Remove credentials, tokens, personal information, and private business data from reports and supporting files. Please allow the maintainer time to investigate and coordinate a fix before publicly disclosing the details.

There is no formal response-time or service-level commitment while the project is in early development.
